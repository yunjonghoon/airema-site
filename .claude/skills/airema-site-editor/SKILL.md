# 아이레마 사이트 편집기

회사명은 **아이레마(AI.ReMa)**, **해동가적(海東歌笛)** 은 설립 철학이다. 빌드 과정 없는 정적 사이트이며 한국어/영어/일본어 3개국어로 운영한다. 이 스킬의 목적은 18개 HTML에 걸친 규칙을 하나도 빠뜨리지 않고 지키는 것이다. 규칙을 놓치면 언어판끼리 어긋나고, 사용자가 나중에 일일이 찾아 고쳐야 한다.

## 파일 구조
- 페이지 6종: `index` `airema` `maista` `entertainment-ax` `sports-ax` `smb-ax`
- 각 페이지는 3개 파일: `이름.html`(한국어), `이름-en.html`, `이름-ja.html`. 세 파일은 같은 구조이고 **본문 텍스트가 각 언어로 직접 들어 있다.**
- 공통: `styles.css`, `site.js`(동작), `language-data.js`(영·일 번역 사전, 영/일 페이지에서만 로드)
- `assets/`: 로고, 이미지, 영상, Pretendard 폰트
- HTML은 줄바꿈이 거의 없는 한 줄 압축 형태다. 전체를 읽고 다시 쓰지 말고, 바꿀 문자열을 Grep으로 찾아 Edit로 정확히 교체한다. 통째로 재작성하면 의도치 않은 변경이 생긴다.

## 지켜야 할 규칙

1. **3개국어 동시 반영.** 한 페이지를 고치면 `-en`, `-ja` 같은 위치도 같은 의미로 고친다. 한 언어만 요청받아도, 나머지는 어떻게 할지 묻거나 함께 맞춘다고 알린다.
2. **`language-data.js` 번역 사전.** `site.js`나 JS가 만드는 문구(메뉴 버튼, 프레임워크 탭 내용, 문의 폼 안내 등)는 한국어 원문을 키로 `[영어, 일본어]`를 등록해야 한다. 새 JS 문구를 쓰면 반드시 여기에 추가한다. 빠뜨리면 영/일 페이지에서 한국어가 그대로 나온다.
3. **로고 색.** 어두운 배경에는 `*-dark`(AI.ReMa 글자가 흰색), 밝은 배경에는 `*-light`(남색)를 쓴다. 헤더/히어로는 어두운 배경이라 `logo-aireema-horizontal-dark.webp`다.
4. **회사명의 AI 강조.** 본문 속 AI.ReMa와 철학 표기 HAIDONGGAJEOK의 AI는 `<span class="ai">AI</span>`로 감싸 붉은색으로 표시한다. 새 문구에서 이 단어를 쓸 때 잊기 쉽다.
5. **캐시 갱신.** `styles.css` 또는 `site.js`를 고치면 **모든 HTML**의 `?v=` 값을 새 값으로 바꾼다(현재 형식 `20261104-v4c`, 날짜-버전). 일부만 바꾸면 페이지마다 다른 CSS가 로드된다. 전체 교체 전에 `grep -o '?v=[^"]*' *.html`로 현재 값을 확인한다.
6. **새 페이지 추가 시:** 기존 비슷한 페이지를 3개 모두 복사해 시작하고, 각 파일의 `<html lang>`, `hreflang` 3줄, `<title>`/description/og 메타, 언어 선택 `<select>`의 3개 옵션, 헤더 메뉴 링크를 새 페이지에 맞게 고친다. 메뉴에 노출할 페이지면 기존 6종 페이지의 `nav`에도 링크를 넣는다.
7. **접근성/반응형 유지.** 기존 `aria-*` 속성, `skip` 링크, 모션 감소 설정 처리를 지우지 않는다.

## 작업 순서
1. 수정 대상 문자열/섹션을 Grep으로 3개 언어판에서 찾는다.
2. 한국어 → 영어 → 일본어 순서로 수정한다. 번역은 기존 문체(간결한 마케팅 톤)에 맞춘다.
3. JS 문구면 `language-data.js`, CSS/JS 변경이면 `?v=` 갱신.
4. **마무리 점검:** 아래 항목을 확인하고 결과를 한두 줄로 보고한다.
   - 3개 언어판이 모두 수정되었는가
   - 새 JS 문구가 `language-data.js`에 있는가
   - AI 강조 span, 로고 dark/light가 맞는가
   - CSS/JS를 바꿨다면 `?v=`가 18개 HTML에서 동일한가
5. 가능하면 브라우저로 한국어/영어/일본어 중 최소 한 페이지를 열어 깨짐을 확인한다.
6. 사용자가 요청할 때만 커밋한다. 메시지는 한국어로 짧게.

## 하지 말 것
- 요청하지 않은 디자인 변경, 파일 전체 재작성, 프레임워크 도입
- `table.html`, `preview.html`은 이 사이트와 무관한 연습 파일이므로 건드리지 않는다.
